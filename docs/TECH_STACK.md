# Технологічний стек MoneyTalks

## Архітектура

- **Клієнт–сервер**: мобільний застосунок звертається до REST API; дані та облікові записи зберігаються на сервері.
- **Репозиторій**: монорепозиторій з двома основними каталогами — `backend/` та `mobile/`.

## Бекенд (`backend/`)

| Компонент | Технологія | Примітки |
|-----------|------------|----------|
| Мова / рантайм | PHP **8.4** (цільовий рантайм у DDEV) | У `composer.json` зазначено сумісність з PHP **^8.3**; локально на хості можливі обмеження через залежності Symfony — для збірки та тестів краще використовувати `ddev exec`. |
| Фреймворк | **Laravel 13** | Маршрути, ORM, валідація, міграції. |
| API | **REST** + JSON | Префікс `/api`. |
| Автентифікація API | **Laravel Sanctum** (personal access tokens) | Поточний MVP: прив’язка до пристрою через `device_uuid`, видача Bearer-токена. |
| База даних | **MariaDB 10.11** (DDEV) / **SQLite** (швидкий локальний режим без DDEV) | Налаштування через `.env`. |
| Черги / кеш (за замовчуванням Laravel) | database driver | Можна розширити Redis у продакшені. |
| CORS | `config/cors.php` | Шляхи `api/*`. |
| Локальне середовище | **DDEV** | Конфігурація: `backend/.ddev/config.yaml` (тип `laravel`, `docroot: public`, Node 22 для фронтових скриптів Laravel за потреби). |
| Документація API | **Knuckles Scribe** (`knuckleswtf/scribe`, dev) | Генерація **статичних** файлів у `backend/public/docs/`: HTML, `openapi.yaml`, `collection.json`. Команда: `composer run docs` у `backend/`. Не потребує Scribe у runtime на production. |

## Мобільний клієнт (`mobile/`)

| Компонент | Технологія | Примітки |
|-----------|------------|----------|
| Платформа | **Expo (SDK 54)** | Один проєкт для iOS та Android, швидкий старт, Expo Go / dev build. |
| UI | **React Native 0.81** + **React 19.1** | Декларативний UI, не Vue (для нативного мобільного стеку обрано RN). |
| Мова | **TypeScript** | Строга типізація для API та стану. |
| Зберігання на пристрої | **AsyncStorage** | Токен API та стабільний `device_uuid`. |
| Криптографія / UUID | **expo-crypto** | Генерація `device_uuid`. |
| Конфіг API | **`EXPO_PUBLIC_API_URL`** | Базовий origin без завершального слешу; див. `mobile/.env.example`. |

### Поточний стан mobile UI

- Один основний екран без складної навігації.
- Автологін через `device_uuid`.
- Баланс, підсумки та помісячний графік на стартовому екрані.
- Список транзакцій з pull-to-refresh.
- Додавання транзакції через modal sheet.
- Видалення транзакції через long press.
- Демо-дані для швидкого наповнення нового акаунта.

## Інструменти розробки

- **Git** — версіонування.
- **Composer** — PHP-залежності бекенду.
- **npm** — залежності мобільного застосунку та (за потреби) Vite у Laravel.
- **Node.js 20.19+** — мінімум для Expo SDK 54.
- **Емулятори**: iOS Simulator (Xcode), Android Emulator (Android Studio) через `npx expo start` → клавіші `i` / `a`.

## Свідомо не обрано в MVP

- **Vue на мобільному** — не використовується; альтернатива з Vue: **Capacitor + Vue** (окремий проєкт або гібрид).
- **GraphQL**, **gRPC** — не входять у поточний обсяг.
- **Окремий BFF** — не потрібен при простому REST.
