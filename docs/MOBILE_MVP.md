# Mobile MVP Status

Описує **поточний стан Expo-клієнта** в `mobile/` станом на **2026-05-18**. Застосунок пройшов масштабний рефакторинг і тепер має повноцінну навігаційну архітектуру.

## Runtime baseline

- Expo SDK 54
- React Native 0.81
- React 19.1
- Node.js 20.19+ для локального запуску Expo

## Архітектура та UI/UX

- Повноцінна маршрутизація через **`expo-router`** (file-based routing: `app/(auth)` та `app/(app)`).
- Tab-based навігація з використанням Safe Area Insets для адаптації під "чубчики" та панелі жестів.
- Сучасний **глобальний `ThemeContext`** з підтримкою світлої/темної теми (перемикання "на льоту").
- Меню (через кнопку ⋮) для доступу до додаткових розділів.

## Що зараз реалізовано

- **Автентифікація:** 
  - Реєстрація та вхід через Email / Password (Sanctum Bearer token).
  - Автоматичне збереження та відновлення сесії (`AsyncStorage`).
- **Головний екран (Dashboard):**
  - Поточний баланс.
  - Останні транзакції.
  - Швидкі дії.
- **Нова транзакція:**
  - Вказання типу, суми, категорії, нотатки.
- **Статистика (Statistics):**
  - Підсумки доходів/витрат.
  - Розрахунок норми заощаджень.
  - Стекова горизонтальна діаграма розподілу по категоріям.
  - Стовпчикова діаграма по місяцях.
- **Всі транзакції:**
  - Фільтрація (всі, доходи, витрати).
  - Редагування через натискання на транзакцію.
  - Видалення транзакції через long-press з підтвердженням.
- **Налаштування та Профіль:**
  - Зміна імені.
  - Керування темою.
  - Тестування локальних Push-сповіщень.

## Інтеграції та фічі

- **Push-сповіщення:** інтегровано `expo-notifications`. Локальне планування сповіщень при тестуванні в налаштуваннях (завантажується остання транзакція і виводиться в Push).
- **Сідер демо-даних:** Створено `DemoUserSeeder` на бекенді, який генерує багату історію транзакцій за 90 днів для презентації.

## Які API використовує клієнт

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/user`
- `PATCH /api/profile`
- `GET /api/transactions`
- `POST /api/transactions`
- `PUT /api/transactions/{id}`
- `DELETE /api/transactions/{id}`
- `GET /api/stats/summary`

## Як показувати демо

1. Підняти Laravel API (`php artisan serve --host=0.0.0.0 --port=8000`).
2. Запустити сідер демо-даних на бекенді: `php artisan db:seed --class=DemoUserSeeder`
3. У `mobile/.env` переконатися, що `EXPO_PUBLIC_API_URL` відповідає локальному IP (або домену ddev).
4. Запустити Expo: `npx expo start --clear`.
5. Увійти з email `demo@moneytalks.com` та паролем `password`.
